# komet-guided-workflow-plugin

The guided workflow, as a Komet plugin: a named list of steps that Komet shows on a card beside
the document the steps write. Rules give each step its state from what is stored, a tool, the
model or a person performs each step, and any step can be done again. The first workflow takes a
510(k) submission from its eSTAR export into the knowledge base.

The design is the topic `dev-guided-workflow` in `ike-lab-documents`.

Built as a member of the `ike-komet-wsr` working set. Tracked in
[IKE-Network/ike-issues#1390](https://github.com/IKE-Network/ike-issues/issues/1390).
